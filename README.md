## 📌 Description

Cette application web permet aux utilisateurs de :
- Consulter les restaurants et les menus
- Passer des commandes
- Gérer l’authentification avec rôles (`Client`, `Admin`, `Livreur`)
- Visualiser les produits
- Simuler une livraison (Google Maps prévu)
---

## 🏗️ Architecture du Projet

- **Frontend** : React.js (dossier `front-commande-app`)
- **Backend** : Spring Boot (dossier `commande-app`)
- **Base de données** : MySQL
- **API REST** : Communication entre React et Spring via JSON
- **Sécurité** : Spring Security + JWT
